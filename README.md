# Lift Log

手機優先的重訓課表小工具，支援 iPhone 與 Mac Safari。沒有帳號、沒有追蹤碼；你調整的課表只會儲存在自己的瀏覽器中。

## 使用方式

1. 直接以瀏覽器開啟 `index.html`，或部署到任一靜態網站服務。
2. 用上方頁籤切換週一、週三、週五課表。
3. 選擇「新增訓練動作」，依序從 **訓練部位 → 器材類型 → 動作** 選取，設定組數與每組次數後儲存。
4. 點開動作卡，可按組數逐組勾選完成狀態並填寫每組重量。
5. 訓練日可以重新命名、新增或刪除；動作選單沒有需要的項目時，可直接輸入自訂動作名稱。
6. 運動完成後選擇日期匯入月曆，也可補登先前忘記保存的訓練；同一天支援多筆記錄。

## 內建內容

- 預設週一胸＋三頭、週三背＋二頭、週五肩＋二頭＋三頭＋核心。
- 常見胸、背、肩、二頭、三頭、腿、核心動作。
- 器材包含滑輪、固定器械、史密斯、槓鈴、啞鈴與徒手。
- 逐組完成與重量追蹤，以及可補登日期的月曆歷史記錄。

## 資料保存

課表使用瀏覽器的 `localStorage` 儲存。清除瀏覽器網站資料、使用無痕模式或換裝置時，不會自動帶過去；這是刻意採用的第一版隱私設計。
